IMPORTANT: Manual Step Required for Auto-Update

Due to network restrictions in the environment, the 'Plugin Update Checker' library could not be downloaded automatically.

Please follow these steps to enable GitHub Auto-Updates:

1. Download the library zip file:
   https://github.com/YahnisElsts/plugin-update-checker/releases/latest/download/plugin-update-checker.zip

2. Extract the zip file.
   You will get a folder named 'plugin-update-checker'.

3. Place this folder into:
   wp-content/plugins/gov-hybrid-translator/inc/Libraries/

   The final path to the main file should be:
   .../inc/Libraries/plugin-update-checker/plugin-update-checker.php

4. Once placed, the plugin will automatically detect it and enable the update checker.
